# Regdel

VB6 Reg Delete CLI (`RegDel.exe` / `Regdel.vbp`): command-line helper that deletes a registry key or value (`Key,ROOT\...` or `Value,ROOT\... NAME`) under HKCU/HKCR/HKLM/HKU. Open `Regdel.vbp` in the VB6 IDE.
